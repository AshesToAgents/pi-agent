# Description

This is my personal pi agent setup. There are many like it, but this one is mine ;)

# Recommended Plugins

[pi-superpowers](https://github.com/coctostan/pi-superpowers), a modified version of the [claude superpowers plugin](https://github.com/obra/superpowers) for pi
[pi-web-tools](https://github.com/SunflowerFuchs/pi-web-tools), my own version of the claude web tools
[pi-subagent-review](https://github.com/SunflowerFuchs/pi-subagent-review), a collection of code reviewers for git branches, using the subagent extension included with this repository
