# Description

This is my personal pi agent setup. There are many like it, but this one is mine ;)

# Recommended Plugins

- [pi-superpowers](https://github.com/coctostan/pi-superpowers), a modified version of the [claude superpowers plugin](https://github.com/obra/superpowers) for pi
- [pi-web-tools](https://github.com/AshesToAgents/pi-web-tools), my own version of the claude web tools
- [pi-subagent-review](https://github.com/AshesToAgents/pi-subagent-review), a collection of code reviewers for git branches, using the subagent extension included with this repository
- [pi-subagents](https://github.com/AshesToAgents/pi-subagents), subagent orchestration tools — delegate tasks to specialized agents with isolated context windows
- [pi-ask-user](https://github.com/AshesToAgents/pi-ask-user), adds an `askUser` tool for interactive user questions in the Pi TUI
- [pi-transcript](https://github.com/AshesToAgents/pi-transcript), session transcript viewing and automatic session naming
- [pi-alerter](https://github.com/AshesToAgents/pi-alerter), native desktop notifications for agent events like waiting prompts
- [pi-hooks](https://github.com/AshesToAgents/pi-hooks), lifecycle hooks — configurable scripts and HTTP endpoints that run automatically in response to agent events
- [pi-smart-commit](https://github.com/AshesToAgents/pi-smart-commit), replaces the built-in `commit` tool with a smarter version that ensures user review before committing
- [pi-context-inspector](https://github.com/AshesToAgents/pi-context-inspector), commands to inspect context window usage and view the effective system prompt
- [pi-shell-completion](https://github.com/AshesToAgents/pi-shell-completion), shell completion scripts for pi (bash and zsh)
- [pi-default-tools](https://github.com/AshesToAgents/pi-default-tools), automatically adds `grep`, `find`, and `ls` to the active toolset when a session starts
- [pi-custom-footer](https://github.com/AshesToAgents/pi-custom-footer), replaces the default footer with a custom status bar showing cwd, git branch, context usage, and model info
- [pi-api-usage](https://github.com/AshesToAgents/pi-api-usage), displays API usage and rate limit information in the status bar with a detailed `/usage` command
- [pi-token-tracker](https://github.com/AshesToAgents/pi-token-tracker), tracks model token usage across sessions with a `/token-usage` command and SQLite-backed history
- [pi-agent-browser](https://github.com/AshesToAgents/pi-agent-browser), browser automation via Chrome DevTools Protocol — integrates agent-browser with skills for web interaction, Electron app automation, and exploratory testing
- [pi-session-share](https://github.com/AshesToAgents/pi-session-share), publish sessions as rendered HTML pages on a self-hosted server with `/publish` and `/unpublish` commands
