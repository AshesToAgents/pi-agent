# Description

This is my personal pi agent setup. There are many like it, but this one is mine ;)

# Recommended Plugins

[pi-superpowers](https://github.com/coctostan/pi-superpowers), a modified version of the [claude superpowers plugin](https://github.com/obra/superpowers) for pi
[pi-web-tools](https://github.com/SunflowerFuchs/pi-web-tools), my own version of the claude web tools
[pi-subagent-review](https://github.com/SunflowerFuchs/pi-subagent-review), a collection of code reviewers for git branches, using the subagent extension included with this repository
[pi-subagents](https://github.com/SunflowerFuchs/pi-subagents), subagent orchestration tools — delegate tasks to specialized agents with isolated context windows
[pi-ask-user](https://github.com/SunflowerFuchs/pi-ask-user), adds an `askUser` tool for interactive user questions in the Pi TUI
[pi-transcript](https://github.com/SunflowerFuchs/pi-transcript), session transcript viewing and automatic session naming
[pi-alerter](https://github.com/SunflowerFuchs/pi-alerter), native desktop notifications for agent events like waiting prompts
[pi-hooks](https://github.com/SunflowerFuchs/pi-hooks), lifecycle hooks — configurable scripts and HTTP endpoints that run automatically in response to agent events
[pi-smart-commit](https://github.com/SunflowerFuchs/pi-smart-commit), replaces the built-in `commit` tool with a smarter version that ensures user review before committing
[pi-context-inspector](https://github.com/SunflowerFuchs/pi-context-inspector), commands to inspect context window usage and view the effective system prompt
[pi-shell-completion](https://github.com/SunflowerFuchs/pi-shell-completion), shell completion scripts for pi (bash and zsh)
[pi-default-tools](https://github.com/SunflowerFuchs/pi-default-tools), automatically adds `grep`, `find`, and `ls` to the active toolset when a session starts
[pi-custom-footer](https://github.com/SunflowerFuchs/pi-custom-footer), replaces the default footer with a custom status bar showing cwd, git branch, context usage, and model info
[pi-api-usage](https://github.com/SunflowerFuchs/pi-api-usage), displays API usage and rate limit information in the status bar with a detailed `/usage` command
